# موتو ورلد 29 — إدارة المتجر | Moto World 29 — Store Management

برنامج إدارة متجر قطع غيار الدراجات النارية — مخزون، مبيعات، مشتريات، تقارير الأرباح اليومية والشهرية.

A motorcycle spare-parts store management web application — inventory, sales, purchases, and daily/monthly profit reports.

---

## ✨ الميزات | Features

- 📊 **لوحة القيادة** — أرباح اليوم والشهر، صافي الربح، هامش الربح، رسم بياني لآخر 7 أيام
- 📦 **المخزون** — إضافة/تعديل/حذف المنتجات مع أسعار الشراء والبيع والكميات
- 🛒 **المبيعات** — تسجيل البيع مع تحديث المخزون تلقائياً وحساب الربح
- 🚚 **المشتريات** — تسجيل التزويد مع تحديث المخزون وسعر الشراء
- 📈 **التقارير** — تقارير يومية وشهرية مفصّلة مع الرسوم البيانية
- ⚙️ **الإعدادات** — اسم المتجر، العملة (مقفولة على الدينار الجزائري دج)
- 🇸🇦 **واجهة عربية كاملة (RTL)** مع خط Cairo
- 💾 قاعدة بيانات محلية (SQLite) — البيانات محفوظة على جهازك

---

## 🛠️ التقنيات | Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript 5
- **Database**: Prisma ORM + SQLite
- **Styling**: Tailwind CSS 4 + shadcn/ui
- **Charts**: Recharts
- **Icons**: Lucide React
- **Font**: Cairo (Arabic)

## 🚀 التشغيل | Getting Started

### المتطلبات | Prerequisites

- [Node.js](https://nodejs.org/) 18+ أو [Bun](https://bun.sh/)

### الخطوات | Installation

```bash
# 1. تثبيت الاعتماديات
bun install

# 2. إعداد قاعدة البيانات
bun run db:push

# 3. تشغيل التطبيق
bun run dev
```

ثم افتح المتصفح على: http://localhost:3000

## 📊 النماذج | Database Models

- **Product**: المنتجات (الاسم، الفئة، سعر الشراء، سعر البيع، الكمية)
- **Sale**: المبيعات (المنتج، الكمية، السعر، التكلفة، الربح، التاريخ)
- **Purchase**: المشتريات (المنتج، الكمية، السعر، الإجمالي، التاريخ)
- **Settings**: الإعدادات (اسم المتجر، العملة، الضريبة)

## 🧮 كيف يُحسب الربح | How Profit is Calculated

- **رقم المعاملات (CA)** = مجموع أسعار البيع × الكميات المباعة
- **تكلفة البضاعة (COGS)** = مجموع أسعار الشراء × الكميات المباعة
- **صافي الربح** = رقم المعاملات − تكلفة البضاعة
- **هامش الربح %** = (صافي الربح ÷ رقم المعاملات) × 100
